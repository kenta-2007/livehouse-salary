# ライブハウスバイト給料計算アプリ

ライブハウスのアルバイトでは、公演ごとに勤務時間が変わり、深夜まで働く日もあります。
そのため毎月の給料がいくらになるか把握しづらく、自分用に給料計算プログラムを作りました。

## 機能
- 時給・開始時刻・終了時刻・休憩から、1日の給料を計算
- 日付をまたぐ勤務（例：18:00〜翌1:00）に対応
- 深夜手当（22:00〜翌5:00は1.25倍）
- 残業手当（1日8時間を超えた分は1.25倍）
- 深夜残業（深夜かつ残業の時間は1.50倍）
- 休憩を取った時間帯に応じて、深夜・残業時間を正しく計算

## 使い方
```bash
java Salary.java
```

```
時給（円）: 1200
開始時刻（例 18:00）: 16:00
終了時刻（例 23:30）: 2:00
休憩（分、なしなら0）: 0
通常    : 6時間00分 → 7200円
深夜    : 2時間00分 → 3000円
残業    : 0時間00分 → 0円
深夜残業: 2時間00分 → 3600円
合計    : 13800円
```

## 工夫した点
- **時刻をすべて「0時からの分」に変換**して計算をシンプルにした
- **終了時刻が開始時刻より前なら1440分（24時間）を足す**ことで、日付またぎに対応した
- 勤務時間と深夜帯を数直線上の区間として考え、**2つの区間の重なりを `min` と `max` で求める**関数を作った。この関数を深夜時間・休憩・残業の計算で使い回している
- 作ってみて、**休憩を深夜に取ると給料が変わる**ことに気づき、休憩も時間帯として扱うように改善した
