# ライブハウスバイト給料計算アプリ

ライブハウスのアルバイトでは、公演ごとに勤務時間が変わり、深夜まで働く日もあります。
そのため毎月の給料がいくらになるか、扶養の範囲内に収まるかを把握しづらく、自分用に給料計算アプリを作りました。

## 機能
- 1日の給料を計算
  - 日付をまたぐ勤務（例：18:00〜翌1:00）に対応
  - 深夜手当（22:00〜翌5:00は1.25倍）
  - 残業手当（1日8時間を超えた分は1.25倍）
  - 深夜残業（深夜かつ残業の時間は1.50倍）
  - 休憩を取った時間帯に応じて、深夜・残業時間を正しく計算
- 勤務記録をCSVファイルに保存
- 月ごと・年間の給料の合計を表示
- 扶養ラインまでの残り金額と、今のペースでの年収見込みを表示し、超えそうなら警告

## 使い方
```bash
java Salary.java
```

```
==== 給料計算アプリ ====
1: 勤務を記録する
2: 月・年の合計を見る
3: 終了
```

## 工夫した点
- **時刻をすべて「0時からの分」に変換**して計算をシンプルにした
- **終了時刻が開始時刻より前なら1440分（24時間）を足す**ことで、日付またぎに対応した
- 勤務時間と深夜帯を数直線上の区間として考え、**2つの区間の重なりを `min` と `max` で求める**関数を作った。深夜時間・休憩・残業の計算で使い回している
- 作ってみて**休憩を深夜に取ると給料が変わる**ことに気づき、休憩も時間帯として扱うように改善した
- 機能を増やす前に、**計算部分を関数にまとめるリファクタリング**を行い、記録と集計の両方から使えるようにした
- 給料の記録は個人情報なので、**`.gitignore` で公開リポジトリに含めないようにした**
- 日付の入力ミスでアプリが止まらないよう、**例外処理で聞き直す**ようにした
